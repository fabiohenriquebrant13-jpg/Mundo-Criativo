# Skills da Mundo Criativo

Adaptadas dos três SKILL.md e das três referências enviados pelo usuário.

| Skill | Uso |
|---|---|
| `mundo-criativo-frontend` | Ajustes de aparência, menu e celular preservando o manual |
| `mundo-criativo-acessibilidade-seo` | Auditorias e melhorias com resultados medidos |
| `melhorar-html` | Diagnóstico, implementação, validação e empacotamento no escopo |

Todas usam [o contexto do projeto](PROJETO.md). As referências compartilhadas
ficam em `melhorar-html/references/`: checklist.md, exemplos.md e avaliacoes.md.

Exemplos de pedidos:

- “Use $mundo-criativo-frontend para ajustar o menu no celular, mantendo o visual.”
- “Use $mundo-criativo-acessibilidade-seo para auditar o ZIP atual, sem alterar o site.”
- “Use $melhorar-html para corrigir a FAQ e atualizar os dois HTML e o ZIP.”

Abra uma nova tarefa na branch que contém estes arquivos para que o cliente possa
descobrir as skills. O reconhecimento automático depende do cliente; não é garantido
que uma sessão já aberta atualize seu catálogo. As skills não instalam ferramentas,
não são conteúdo do site e não fazem alterações só por estarem no repositório.
